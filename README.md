# Pratyush Raj Srivastava — Portfolio Website

A modern, responsive, and cinematic personal portfolio website showcasing my work as an **AI & Machine Learning Engineer** specializing in Computer Vision, Deep Learning, and Full-Stack Systems.

---

## 🌟 Overview

- **Live & Interactive:** Ambient canvas particle network, 3D card tilt effects, custom glowing cursor, and smooth navigation.
- **Project Showcase:** Highlights flagship engineering projects including Outlet Intelligence & Navigation Systems and YOLO-based Computer Vision pipelines.
- **Skills Matrix:** Categorized technical expertise across Computer Vision, Machine Learning & Deep Learning, Frontend, Backend, Databases, and Developer Tools.
- **Experience Timeline:** Interactive education and achievement timeline.
- **Contact Hub:** Direct contact channels, resume download, and social profiles.

---

## 🛠️ Tech Stack

- **Markup & Styling:** HTML5, CSS3 (Modular Architecture, CSS Grid & Flexbox, Custom Properties/Variables)
- **Scripting:** Modern JavaScript (ES6+ Modules, HTML5 Canvas API)
- **Visuals & Effects:** Vanilla Tilt JS, Custom Particle Canvas, Dynamic Cursor Tracking
- **Typography:** Outfit (Google Fonts)
- **Deployment:** Vercel

---

## 🚀 Getting Started

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PratyushRaj03/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run local dev server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:8080`.

Or simply open `index.html` directly in your browser.
